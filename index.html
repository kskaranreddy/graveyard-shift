    ☁️ AWS Cloud Integration & Event Log

    AWS Student Builder Group • IIT Jodhpur

    Graveyard Shift is designed to run as a cloud-native serverless solution for Hack-to-Ween 2026. Below is the proposed serverless architecture and a simulated event log (generated in the browser, not from a live AWS account).

    🔌 Connect your AWS backend
    Paste the Function URL from your CloudFormation stack output. Spirits and graves then sync to Amazon DynamoDB through AWS Lambda, and banish incantations are voiced by Amazon Polly.
    ⚡
    AWS Lambda
    Serverless Exorcisms
    Microservices handle BanishSoulHandler, SeanceTelemetryHandler, and boss HP calculations with sub-50ms execution times.
    🗄️
    Amazon DynamoDB
    Spirits & Graves Store
    Single-table schema indexing active spirits (PK: USER#id, SK: SPIRIT#id) and archived tombstones with millisecond latency.
    ⏱️
    Amazon EventBridge
    Midnight Witching Crons
    Schedules daily exorcism reminders, midnight haunt digests, and auto-purges stale ectoplasmic cache.
    📊
    Amazon CloudWatch
    Haunt Observability
    Tracks custom metrics: SoulsBanishedCount, SeanceDurationMinutes, and boss battle damage telemetry.

    ☁️ Hack-to-Ween 2026 Architecture & Rules

    Hackathon Summary

    Hack-to-Ween 2026 is a virtual Halloween-themed hackathon organized by the AWS Student Builder Group, IIT Jodhpur. Participants build innovative solutions combining Halloween UI flair with technical excellence and AWS cloud integration.

    Judging Criteria Alignment:
    • Halloween UI/UX: Eerie gothic typography, procedural Web Audio synthesizer, SVG melting candle, animated graveyard grounds, dynamic haunted themes.
    • Innovation & Practical Value: Gamified focus tool transforming dread of overdue tasks into collectible soul banishments and tombstone monuments.
    • AWS Integration: Architecture built on AWS Lambda, DynamoDB Single-Table Design, EventBridge cron exorcisms, CloudWatch metrics, and browser speech synthesis (Amazon Polly planned).

    Simulated CloudWatch-style Logs

    Every task summoned, session ignited, and spirit banished emits a log line in the style of Amazon CloudWatch (simulated in the browser).
